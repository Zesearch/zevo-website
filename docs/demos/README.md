# Demo videos

Drop each system's demo video here as an `.mp4` (e.g. `reflective-coder.mp4`),
then set the matching system's `video` field in `lib/systems.ts`, for example:

```ts
video: "/demos/reflective-coder.mp4",
```

Optional: add a poster/thumbnail image and set `poster: "/demos/reflective-coder.jpg"`.

Until a `video` is set, the demo player shows a "coming soon" placeholder.
